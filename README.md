## 📖 Sobre o projeto

O **AtlasConnect** é uma plataforma digital de consultoria personalizada voltada para intercambistas.

O sistema foi desenvolvido com o objetivo de proporcionar uma experiência completa ao usuário, integrando:

- 📊 Planejamento estratégico  
- 🎓 Suporte acadêmico  
- 🌎 Adaptação cultural  

A proposta é conectar os usuários a **roteiros personalizados**, alinhando seus objetivos com suas preferências, oferecendo:

- 🎯 Mentorias especializadas  
- 📘 Guia de sobrevivência contextualizado  
- 🤝 Suporte direcionado  

---
